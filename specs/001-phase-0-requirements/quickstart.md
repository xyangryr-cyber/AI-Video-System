# Quickstart: Phase 0 Development

**Date**: 2026-05-02
**Purpose**: Get a working Phase 0 development environment and run the full flow.

## Prerequisites

- Python 3.11+ with `uv` or `pip`
- Node.js 20+ with `pnpm`
- Docker (optional, for containerized dev)
- Git repository at `~/Desktop/硅基员工/AI-Video-System`

## Setup (5 minutes)

### 1. Backend

```bash
cd ~/Desktop/硅基员工/AI-Video-System

# Create virtual environment (if not exists)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt -r requirements-dev.txt

# Initialize data directories
bash scripts/init-data-dirs.sh

# Seed dev database
python scripts/seed_dev_db.py

# Start API server
uvicorn src.backend.api.main:app --reload --port 8000
```

### 2. Frontend

```bash
cd src/frontend

# Install dependencies
pnpm install

# Start dev server
pnpm dev
```

### 3. Worker (for async tasks)

```bash
cd ~/Desktop/硅基员工/AI-Video-System
source .venv/bin/activate

# Start Huey worker
python -m src.backend.workers.run
```

### 4. Verify

```bash
# Backend health check
curl http://localhost:8000/api/system/status

# Frontend
open http://localhost:5173
```

### Alternative: Docker Compose

```bash
docker compose -f docker-compose.dev.yml up -d
# Frontend: http://localhost:3000
# API: http://localhost:8000
```

## Run Phase 0 Flow (Manual Test)

### Step 1: Create Project

```bash
curl -X POST http://localhost:8000/api/projects \
  -H "Content-Type: application/json" \
  -d '{
    "title": "黄金价格走势分析",
    "description": "做一个关于近期黄金价格走势的分析视频，从技术面和基本面两个角度解读，适合投资新手观看，5-8分钟，发布到B站"
  }'
```

Expected: 201 with `project_id`, `current_phase: 0`.

### Step 2: Wait for Artifact Generation

```bash
# Replace with actual project_id
PROJECT_ID="proj_20260502_001"

# Poll for artifact (or watch WebSocket)
curl http://localhost:8000/api/projects/$PROJECT_ID/phases/0/artifact
```

Expected: `requirements.json` with topic, duration, platform, category, word count.

### Step 3: Check Review

```bash
curl http://localhost:8000/api/projects/$PROJECT_ID/tasks?phase=0
```

Expected: `generate_artifact` task succeeded, `review` task completed with verdict.

### Step 4: Revise via Chat

```bash
curl -X POST http://localhost:8000/api/projects/$PROJECT_ID/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "改成8-12分钟，加上抖音平台"}'
```

Expected: Intent `revise`, artifact version incremented, new review triggered.

### Step 5: Advance

```bash
curl -X POST http://localhost:8000/api/projects/$PROJECT_ID/advance
```

Expected: Gate checks pass, Phase 0 completed, Phase 1 active.

## Development Workflow

1. Pick a task card from `tasks/` (generated by `/speckit-tasks`)
2. Write failing test (RED)
3. Implement minimum code (GREEN)
4. Refactor (keep tests green)
5. Run `make check` (lint + type check + unit tests)
6. Commit with `[SPEC-D-XXX]` prefix
7. Update `PROGRESS.md` with one-line commit entry

## Common Issues

| Issue | Fix |
|-------|-----|
| `ModuleNotFoundError: src.backend` | Run from repo root; ensure `.venv` is activated |
| SQLite `database is locked` | Check no other process holds the DB; WAL mode should prevent this |
| WebSocket connection refused | Verify API server is running on port 8000 |
| LLM API calls fail | Check `.env` has valid API keys; check `model_config.json` model names |
| Frontend shows mock data | `WorkflowPage.tsx` has hardcoded imports from `mockData.ts` — replace with API hooks |
| `requirements.json` schema mismatch | RequirementsAgent output needs `_to_canonical()` adapter |
| GateP0 not found | Register `GateP0` in `gate_registry.py` |
